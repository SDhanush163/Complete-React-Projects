## About

A growing collection of standalone React applications built while exploring modern frontend development, application architecture, and full-stack integrations. While **Complete-React** focuses on individual concepts and isolated exercises, this repository focuses on combining those concepts into complete, self-contained applications.

Each project explores a different problem domain and introduces new architectural decisions, UI patterns, and development practices. Rather than continuously expanding a single application, every project starts from a clean slate, making it easier to experiment with different approaches without affecting previous work.

As I continue learning, this repository will grow with additional applications covering new technologies, libraries, and real-world development patterns.

> Related Repository - If you're looking for the concept-based exercises and smaller learning projects, see **[Complete-React](https://github.com/SDhanush163/Complete-React)**.

## Running a Project

### Frontend

| Step                         | Command               |
| ---------------------------- | --------------------- |
| Navigate to a project        | `cd <project-folder>` |
| Install dependencies         | `npm install`         |
| Start the development server | `npm run dev`         |

### Backend (where applicable)

| Step                    | Command                       |
| ----------------------- | ----------------------------- |
| Navigate to the backend | `cd <project-folder>/backend` |
| Install dependencies    | `npm install`                 |
| Start the server        | `npm start`                   |
